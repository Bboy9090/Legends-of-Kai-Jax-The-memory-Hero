## 🎯 Universal Sculpting Workflow

### Phase 1: Blockout Refinement (30 min - 2 hours)
1. **Verify Proportions**
   - Check dimensions match REFERENCE.md
   - Front/Side/Top views
   - Adjust if needed

2. **Refine Overall Shape**
   - Use Grab tool (G)
   - Create character silhouette
   - Work from large to small

3. **Smooth Rough Areas**
   - Hold Shift (smooth brush)
   - Remove blocky geometry
   - Create organic flow

### Phase 2: Primary Forms (2-4 hours)
1. **Body Shape**
   - Sculpt main body form
   - Add muscle definition (subtle)
   - Create character posture

2. **Head/Face**
   - Sculpt head shape
   - Add facial features
   - Create expression

3. **Limbs**
   - Refine arms/legs
   - Add joint definition
   - Create natural flow

### Phase 3: Secondary Details (4-8 hours)
1. **Special Features**
   - Quills/Tails/Blades
   - Armor/Equipment
   - Unique elements

2. **Surface Details**
   - Fur direction
   - Scale patterns
   - Texture hints

3. **Refinement**
   - Polish all areas
   - Check from all angles
   - Smooth transitions

### Phase 4: Polish (2-4 hours)
1. **Final Pass**
   - Smooth everything
   - Refine details
   - Check proportions

2. **Quality Check**
   - All angles look good
   - Silhouette is strong
   - Ready for retopology

## 🛠️ Essential Sculpting Tools

### Primary Tools
- **Grab (G)** - Reshape overall form
- **Draw** - Add detail/volume
- **Smooth (Shift)** - Smooth areas
- **Inflate (I)** - Add volume
- **Crease (K)** - Create sharp edges

### Secondary Tools
- **Clay Strips** - Build up forms
- **Scrape** - Remove volume
- **Pinch** - Sharpen edges
- **Flatten** - Create flat surfaces
- **Mask** - Protect areas

### Controls
- **F** - Brush size
- **Shift+F** - Brush strength
- **X** - Mirror X-axis
- **Ctrl** - Invert (subtract)
- **Alt** - Smooth (while using any brush)

## ✅ Quality Standards

**Model is ready for retopology when:**
- ✅ Proportions match REFERENCE.md exactly
- ✅ Silhouette is strong and recognizable
- ✅ All special features are detailed
- ✅ Surface is smooth (no artifacts)
- ✅ Looks good from all angles

---

## 🚨 Common Mistakes to Avoid

1. **Over-Sculpting** - Less is more (stylized, not realistic)
2. **Ignoring Proportions** - Check REFERENCE.md frequently
3. **Forgetting Special Features** - Quills/tails/armor are critical
4. **Not Checking Angles** - Rotate view constantly
5. **Rushing** - Take time for quality
