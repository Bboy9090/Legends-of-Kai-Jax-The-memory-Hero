## 📋 Universal Workflow

### Phase 1: Blockout Refinement (30 min - 2 hours)
- Verify proportions
- Refine overall shape
- Smooth rough areas

### Phase 2: Primary Forms (2-7 hours)
- Body shape
- Head/face
- Limbs

### Phase 3: Special Features (2-8 hours)
- Quills/Tails/Blades
- Armor/Equipment
- Unique elements

### Phase 4: Surface Details (2-5 hours)
- Fur direction
- Texture hints
- Refinement

### Phase 5: Polish (2-4 hours)
- Final pass
- Quality check
- Ready for retopology

---

## 🛠️ Essential Tools

- **Grab (G)** - Reshape form
- **Draw** - Add detail
- **Smooth (Shift)** - Smooth areas
- **Inflate (I)** - Add volume
- **Crease (K)** - Sharp edges
