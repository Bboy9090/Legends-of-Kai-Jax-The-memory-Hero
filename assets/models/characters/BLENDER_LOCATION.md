# 📍 BLENDER LOCATION GUIDE
## Find Blender on Your System

---

## 🔍 QUICK SEARCH METHODS

### Method 1: Windows Search (Fastest)
```
1. Press Windows key
2. Type: "blender"
3. Look for Blender application
4. Click to open!
```

### Method 2: Check Start Menu
```
1. Click Start Menu
2. Scroll to "B" section
3. Look for "Blender"
4. Click to open
```

### Method 3: Check Desktop
```
Look for Blender shortcut icon on desktop
Double-click to open
```

---

## 📂 COMMON INSTALLATION LOCATIONS

### Windows 64-bit:
```
C:\Program Files\Blender Foundation\Blender [version]\blender.exe
C:\Program Files (x86)\Blender Foundation\Blender [version]\blender.exe
```

### User Installation:
```
C:\Users\[YourName]\AppData\Local\Programs\Blender\blender.exe
```

### Portable Installation:
```
C:\Blender\blender.exe
D:\Blender\blender.exe
(Or wherever you extracted it)
```

---

## 📥 IF BLENDER IS NOT INSTALLED

### Download & Install (5 minutes):

1. **Go to Blender Website**
   ```
   https://www.blender.org/download/
   ```

2. **Download Blender 4.0+**
   - Click "Download Blender"
   - Choose Windows 64-bit
   - Download installer

3. **Install Blender**
   - Run installer
   - Follow prompts
   - Install to default location

4. **Verify Installation**
   - Start Menu → Search "Blender"
   - Should appear!

---

## ✅ VERIFY BLENDER VERSION

**Once Blender is open:**
1. **Help → About Blender**
2. **Check version number**
3. **Need:** 4.0 or newer

**If version is too old:**
- Download latest from blender.org
- Install new version
