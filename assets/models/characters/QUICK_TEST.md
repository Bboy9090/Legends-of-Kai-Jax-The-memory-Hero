# ⚡ Quick Test - 5 Minutes
## Fast Verification of All Scripts

**Time:** 5 minutes  
**Purpose:** Quick verification all scripts work

---

## 🚀 Super Quick Test

### Option 1: Test Single Character (1 min)

1. **Open Blender**
2. **Load Script:**
   ```
   Text Editor → Open → [character]/blender_scripts/generate_[character]_blockout.py
   ```
3. **Run:** Alt+P
4. **Check:** Model appears, colors correct

### Option 2: Test All Characters (5 min)

1. **Open Blender**
2. **Load Test Script:**
   ```
   Text Editor → Open → blender_scripts/test_all_blockouts.py
   ```
3. **Run:** Alt+P
4. **Check Console:** All tests should pass

---

## ✅ Quick Checklist

For each character, quickly verify:
- [ ] Script runs (no errors in console)
- [ ] Model appears in viewport
- [ ] Correct color/material
- [ ] Special features visible
- [ ] Looks like Beast-Kin form (not Nintendo)

## 🚨 If Something's Wrong

1. **Check Console** - Look for error messages
2. **Check Blender Version** - Need 4.0+
3. **Check Script Path** - Verify file exists
4. **Check Materials** - Switch to Material Preview mode
