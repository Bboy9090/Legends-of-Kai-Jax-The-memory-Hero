## 🚀 Quick Start (Any Character)

### Step 1: Run Helper Script (2 min)
```
1. Open Blender with high-poly sculpt
2. Text Editor → Open → retopology_helper.py
3. Alt+P (run script)
4. Base mesh + Shrinkwrap created!
```

### Step 2: Build Topology (3-6 hours)
```
1. Edit Mode (Tab)
2. Loop Cut (Ctrl+R) - Add edge loops
3. Proportional Editing (O) - Match high-poly
4. Maintain quads
```

### Step 3: UV Unwrap (1-2 hours)
```
1. Mark seams (Ctrl+E → Mark Seam)
2. Unwrap (U → Unwrap)
3. Pack (UV → Pack Islands)
```

## 📋 Workflow Summary

### Phase 1: Setup (30 min)
- Duplicate high-poly
- Create base mesh
- Add Shrinkwrap

### Phase 2: Build Topology (3-6 hours)
- Add edge loops
- Refine shape
- Match high-poly

### Phase 3: Special Features (1-3 hours)
- Quills/Tails/Blades
- Clean topology
- Animation-ready

### Phase 4: UV Unwrapping (1-2 hours)
- Mark seams
- Unwrap
- Pack

### Phase 5: Quality Check (30 min)
- Verify topology
- Check polycount
- Verify UVs

## ✅ Success Criteria

**Retopology is complete when:**
- ✅ Clean quad topology (or clean tris)
- ✅ Edge loops follow muscle flow
- ✅ Joints have extra loops
- ✅ No n-gons
- ✅ Polycount within target
- ✅ UVs unwrapped and packed
- ✅ Ready for texturing
