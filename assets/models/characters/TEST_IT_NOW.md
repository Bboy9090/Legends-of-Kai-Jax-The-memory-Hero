## 🚨 Troubleshooting

### Script doesn't run?
- **Check:** Blender version (need 4.0+)
- **Check:** Console for error messages
- **Fix:** Update Blender or check script path

### Model doesn't appear?
- **Press:** Home (frame all)
- **Check:** If hidden (Alt+H to unhide)
- **Check:** Collection visibility

### Wrong colors?
- **Switch:** Material Preview mode (should be automatic)
- **Check:** Material Properties panel
- **Verify:** Materials are assigned

### Console shows errors?
- **Read:** Error message carefully
- **Check:** Script file exists
- **Check:** Blender version compatibility
