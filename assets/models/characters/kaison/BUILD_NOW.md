## ⚡ FASTEST PATH (5 Minutes to Blockout)

### Step 1: Open Blender
1. Launch Blender 4.0+
2. File → New → General

### Step 2: Load Script
1. Click **Text Editor** tab
2. Click **New** button
3. Click **Open** button
4. Navigate to: `assets/models/characters/kaison/blender_scripts/generate_kaison_blockout.py`
5. Open the file

### Step 3: Run Script
1. Press **Alt+P** (or click Run Script)
2. Wait 5-10 seconds
3. **BOOM!** Kaison blockout appears!

### Step 4: Verify
- You should see:
  - ✅ Golden-Orange body (Beast-Kin Fox)
  - ✅ Head with elongated snout
  - ✅ Arms and legs
  - ✅ 2 energy tails (twin tail system)
  - ✅ 2 amber eyes

### Step 5: Save
- File → Save As
- Name: `Kaison_Blockout_v1.blend`
- Location: `assets/models/characters/kaison/`

**✅ DONE! Beast-Kin blockout complete in 5 minutes!**

## 🚀 Next: Begin Sculpting

### Immediate Next Steps

1. **Check Proportions**
   ```
   NumPad 1: Front view
   NumPad 3: Side view
   NumPad 7: Top view
   ```
   - Verify dimensions match REFERENCE.md
   - Check twin tails positioned correctly

2. **Add Subdivision** (Already added by script)
   - Should see: Subdivision Surface modifier
   - Levels: 2 (Viewport), 3 (Render)

3. **Enter Sculpt Mode**
   - Tab → Sculpt Mode
   - Or: Mode menu → Sculpt Mode

4. **Start Sculpting**
   - Use **Grab (G)** to reshape body
   - Use **Smooth (Shift)** to smooth rough areas
   - Refine fox snout
   - Detail the twin tails
