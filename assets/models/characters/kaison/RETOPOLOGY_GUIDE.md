# Kaison Retopology Guide
## Clean Topology for Twin Tails

**Character:** Kaison - The Swift Guardian 🦊  
**Estimated Time:** 4-8 hours  
**Target Polycount:** 30,000-40,000 tris (LOD0)

---

## 🚀 Phase 1: Setup (30 min)

### Step 1.1: Prepare High-Poly
1. **Duplicate Sculpt** → Hide original
2. **Create Base Mesh** → UV Sphere
3. **Add Shrinkwrap** → Target high-poly

---

## 🔧 Phase 2: Body Topology (2-4 hours)

### Step 2.1: Build Base Topology

**Edge Loops:**
- Horizontal: Chest, Waist, Hips
- Vertical: Front, Sides, Back
- Joints: Shoulders (2-3), Elbows (2), Hips (2-3), Knees (2)

### Step 2.2: Head Topology

**Fox Head:**
- Face loops: Eyes, Mouth, Snout
- Head loops: Horizontal, Vertical
- **Key:** Elongated snout topology

---

## 🦊 Phase 3: Twin Tail Topology (2-3 hours)

### Step 3.1: Tail Base Topology

**Each of 2 Tails:**
1. **Create Tail Base**
   - Start with cylinder
   - 8-12 sides
   - Match tail position

2. **Refine Tail Shape**
   - Use Shrinkwrap
   - Match high-poly
   - Energy-like flow

### Step 3.2: Tail Edge Loops

**Tail Topology:**
- Base loop (attachment)
- Mid loops (4 flex points)
- Tip loop (end point)
- **Total:** 10 bones per tail

---

## 🎨 Phase 4: UV Unwrapping (2-4 hours)

### Step 4.1: Mark Seams
- Under arms
- Inner legs
- Back center
- Around tail bases

### Step 4.2: Unwrap & Pack
- Unwrap (U)
- Pack Islands
- 80-90% usage

---

## ✅ Quality Check

- [ ] Polycount: 30,000-40,000 tris
- [ ] All quads
- [ ] Twin tails: 10 bones each
- [ ] UVs unwrapped
- [ ] Ready for texturing

---

**Ready?** Start retopology! 🦊
