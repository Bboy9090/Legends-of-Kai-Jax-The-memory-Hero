# Sentinel Vox Retopology Guide
## Clean Topology for Tail-Blades

**Character:** Sentinel Vox - Star-Force Pilot 🦊  
**Estimated Time:** 4-8 hours  
**Target Polycount:** 40,000-50,000 tris (LOD0)

---

## 🚀 Phase 1: Setup (30 min)

### Step 1.1: Prepare High-Poly
1. **Duplicate Sculpt** → Hide original
2. **Create Base Mesh** → UV Sphere (muscular)
3. **Add Shrinkwrap** → Target high-poly

---

## 🔧 Phase 2: Body Topology (2-4 hours)

### Step 2.1: Build Muscular Topology

**Edge Loops:**
- Horizontal: Chest, Waist, Hips
- Vertical: Front, Sides, Back
- **Key:** Muscular build (1.2x proportions)

### Step 2.2: Head Topology

**Fox Head:**
- Face loops: Eyes, Mouth, Snout
- Head loops: Horizontal, Vertical
- **Key:** Pilot expression ready

---

## ⚡ Phase 3: Tail-Blade System (2-4 hours)

### Step 3.1: Tail-Blade Topology

**Mechanical Tail-Blades:**
1. **Create Blade Base**
   - Start with cylinder
   - 8-12 sides
   - Segmented design

2. **Refine Blade Shape**
   - Use Shrinkwrap
   - Match high-poly
   - Mechanical ready

3. **Blade Edge Loops**
   - Base loop
   - Mid loops (articulation)
   - Tip loop
   - **Total:** 8 bones per blade
   - **Start:** 2 blades (16 bones)
   - **Extend:** Up to 9 blades (72 bones)

---

## 🎨 Phase 4: UV Unwrapping (2-4 hours)

### Step 4.1: Mark Seams
- Under arms
- Inner legs
- Back center
- Around tail-blade bases

### Step 4.2: Unwrap & Pack
- Unwrap (U)
- Pack Islands
- 80-90% usage

---

## ✅ Quality Check

- [ ] Polycount: 40,000-50,000 tris
- [ ] All quads
- [ ] Tail-blades: 8 bones each
- [ ] UVs unwrapped
- [ ] Ready for texturing

---

**Ready?** Start retopology! 🦊
