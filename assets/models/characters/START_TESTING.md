## 🚨 If Something's Wrong

### Script doesn't run?
- Check Blender version (need 4.0+)
- Check console for error messages
- Verify file path is correct

### Model doesn't appear?
- Press **Home** (frame all)
- Check if hidden: **Alt+H** (unhide all)
- Check collection visibility

### Wrong colors?
- Switch to **Material Preview** mode (should be automatic)
- Check **Material Properties** panel
- Verify materials are assigned

### Missing features?
- Check console for errors
- Verify all parts were created
- Check if parts are separate objects (should be joined)
