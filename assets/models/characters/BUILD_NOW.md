## ⚡ QUICK START (3 Steps)

### Step 1: Open Blender
```
1. Open Blender 4.0+
2. New File (or clear scene)
```

### Step 2: Run Blockout Script
```
1. Text Editor tab
2. Open: assets/models/characters/jaxon/blender_scripts/generate_jaxon_blockout.py
3. Press Alt+P (run script)
4. Wait 5-10 seconds
5. JAXON BLOCKOUT APPEARS! 🦔
```

### Step 3: Begin Sculpting
```
1. Select Jaxon blockout
2. Tab → Sculpting Mode
3. Follow: jaxon/SCULPTING_GUIDE.md
4. Start sculpting!
```
