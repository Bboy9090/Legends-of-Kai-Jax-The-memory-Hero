## 🚀 Quick Start

### For Any Character:

1. **Setup Retopology**
   ```
   Run: retopology_helper.py
   Creates base mesh + Shrinkwrap
   ```

2. **Build Topology**
   ```
   Edit Mode → Loop Cut (Ctrl+R)
   Add loops → Refine shape
   ```

3. **UV Unwrap**
   ```
   Mark seams → Unwrap → Pack
   ```
