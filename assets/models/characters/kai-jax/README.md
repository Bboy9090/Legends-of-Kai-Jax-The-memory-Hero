This directory contains all assets and specifications for Kai-Jax, the Memory Hero.


## Quick Start

### 1. Generate Base Model

**Requirements:** Blender 3.0+

```bash
cd assets/models/characters/kai-jax/blender_scripts
blender --background --python generate_kai_jax_complete.py
```

**Output:** `server/public/models/kai_jax_hero.glb`

### 2. Verify Model

```bash
# Run canonical validation
npm run validate:canon

# Check model structure
python3 -c "
import json, struct

with open('server/public/models/kai_jax_hero.glb', 'rb') as f:
    f.seek(12)  # Skip GLB header
    json_length = struct.unpack('<I', f.read(4))[0]
    f.read(4)  # Skip chunk type
    gltf = json.loads(f.read(json_length))
    
    print('Meshes:', len(gltf.get('meshes', [])))
    print('Materials:', len(gltf.get('materials', [])))
    print('Animations:', len(gltf.get('animations', [])))
    
    if 'skins' in gltf:
        for i, skin in enumerate(gltf['skins']):
            print(f'Skin {i}: {len(skin.get(\"joints\", []))} bones')
"
```

## Canonical Requirements

**FROM:** `/kai_jax.character.json` (LOCKFILE)

### Non-Negotiable

- **Tail Count:** EXACTLY 9 (evolution.final_tail_count)
- **Tail Bones:** 5-7 bones per tail (rigging.extra_bones.tails.bones_per_tail)
- **Starting Tails:** 3 active (evolution.starting_tail_count)
- **Unlock Rule:** Sequential only 3→4→5→6→7→8→9
- **Physics:** No noodle physics (constraints.noodle_physics: false)

### LOD Targets

```
LOD0: 80,000 - 120,000 triangles
LOD1: 50,000 - 70,000 triangles
LOD2: 25,000 - 35,000 triangles
```

### Materials

1. **Fur** (PBR) - Charcoal base, card/shell method
2. **Armor** (PBR) - Worn foundry steel, edge wear required
3. **Spikes** (PBR) - Bone-tech hybrid, event-triggered emissive
4. **Weave Energy** (PBR) - Memory blue (#88d0ff), emissive 2.0

## Troubleshooting

### "Blender script fails with JSON error"
**Fix:** Ensure `kai_jax.character.json` exists in repo root and is valid JSON.

### "Model has wrong tail count"
**Fix:** Check `kai_jax.character.json` → `anatomy.tail_count` and `rigging.extra_bones.tails.count`. Must both be 9.

### "Tails look like noodles"
**Fix:** Apply physics constraints in Blender:
- Limit Rotation constraint on each tail bone
- X: ±45°, Y: ±30°, Z: ±20°

### "Materials don't show in game"
**Fix:** Ensure materials are named exactly:
- `KaiJax_Fur`
- `KaiJax_Armor`
- `KaiJax_WeaveEnergy`
