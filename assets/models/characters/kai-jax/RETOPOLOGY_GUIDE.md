# Kai-Jax Retopology Guide
## Clean Topology for 3 Memory Tails

**Character:** Kai-Jax - The Memory Hero ⚡🦊🦔  
**Estimated Time:** 5-9 hours  
**Target Polycount:** 40,000-50,000 tris (LOD0)

---

## 🚀 Phase 1: Setup (30 min)

### Step 1.1: Prepare High-Poly
1. **Duplicate Sculpt** → Hide original
2. **Create Base Mesh** → UV Sphere (spherical)
3. **Add Shrinkwrap** → Target high-poly

---

## 🔧 Phase 2: Spherical Body Topology (3-5 hours)

### Step 2.1: Build Spherical Topology

**Maintain Round Shape:**
- Horizontal loops (around sphere)
- Vertical loops (top to bottom)
- **Key:** Keep spherical form

### Step 2.2: Limb Topology

**Compact Limbs:**
- Arms: Clean loops
- Legs: Clean loops
- **Key:** Smooth integration with body

---

## ⚡ Phase 3: Three Memory Tails (2-4 hours)

### Step 3.1: Tail Topology

**Each of 3 Tails:**
1. **Gold Tail (Velocity)**
   - 10 bones
   - Liquid ink ready
   - Speed-focused

2. **Blue Tail (Shielding)**
   - 10 bones
   - Semi-solid ready
   - Defensive

3. **White Tail (Harmony)**
   - 10 bones
   - Ghostly ready
   - Ethereal

### Step 3.2: Quill Topology

**6 Quills:**
- 8-12 sides each
- Clean edge loops
- Animation-ready

---

## 🎨 Phase 4: UV Unwrapping (2-4 hours)

### Step 4.1: Mark Seams
- Body seams
- Tail seams
- Quill seams

### Step 4.2: Unwrap & Pack
- Unwrap (U)
- Pack Islands
- 80-90% usage

---
