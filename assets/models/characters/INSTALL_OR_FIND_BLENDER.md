# 🔍 FIND OR INSTALL BLENDER
## Step-by-Step Guide

**Status:** Blender not found in PATH  
**Action Needed:** Find existing Blender OR Install Blender

---

## 🔎 STEP 1: Check if Blender is Already Installed

### Quick Check:
1. **Press Windows Key**
2. **Type:** "blender"
3. **Look for:** Blender application
4. **If found:** Click to open! ✅

### Check Common Locations:
```
C:\Program Files\Blender Foundation\
C:\Program Files (x86)\Blender Foundation\
C:\Users\[YourName]\AppData\Local\Programs\Blender\
```

**Open File Explorer and check these folders!**

---

## 📥 STEP 2: If Blender is NOT Installed

### Download Blender (FREE):

1. **Go to Blender Website**
   ```
   https://www.blender.org/download/
   ```

2. **Download Blender 4.0+**
   - Click "Download Blender" button
   - Choose: **Windows 64-bit**
   - File size: ~300MB
   - Download time: 2-5 minutes

3. **Install Blender**
   - Run the downloaded installer (.exe file)
   - Follow installation wizard
   - Install to default location
   - **Check:** "Add Blender to system PATH" (if option available)

4. **Verify Installation**
   - Start Menu → Search "Blender"
   - Should appear!
   - Click to open

---

## ✅ STEP 3: Once Blender is Open

### Test the Scripts:

1. **In Blender:**
   - Click "Text Editor" tab (top)
   - Click "New" → "Open"
   - Navigate to: `assets/models/characters/blender_scripts/`
   - Open: `quick_test_jaxon.py`

2. **Run Script:**
   - Press **Alt+P**
   - Watch viewport!

3. **You Should See:**
   - Electric Blue hedgehog
   - 7 blue quills
   - 2 green eyes
   - ✅ SUCCESS!
