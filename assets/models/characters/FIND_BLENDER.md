# 🔍 FIND BLENDER - Where Is It?
## How to Find or Install Blender

---

## 🔎 CHECK IF BLENDER IS INSTALLED

### Method 1: Check Start Menu
1. **Click Start Menu** (Windows key)
2. **Type:** "Blender"
3. **Look for:** Blender application
4. **If found:** Click to open!

### Method 2: Check Program Files
1. **Open File Explorer**
2. **Navigate to:** `C:\Program Files\Blender Foundation\`
3. **Look for:** Blender folder
4. **If found:** Open `blender.exe`

### Method 3: Check Common Locations
```
C:\Program Files\Blender Foundation\Blender [version]\blender.exe
C:\Program Files (x86)\Blender Foundation\Blender [version]\blender.exe
C:\Users\[YourName]\AppData\Local\Programs\Blender\blender.exe
```

---

## 📥 IF BLENDER IS NOT INSTALLED

### Install Blender (5 minutes):

1. **Download Blender**
   - Go to: https://www.blender.org/download/
   - Click "Download Blender"
   - Choose: **Blender 4.0 or newer** (required!)

2. **Install Blender**
   - Run the installer
   - Follow installation steps
   - **Important:** Check "Add to PATH" if option available

3. **Verify Installation**
   - Open Start Menu
   - Search "Blender"
   - Should appear!
