## ⚡ FASTEST TEST (Test All at Once)

### Step 1: Open Blender
```
1. Launch Blender 4.0+
2. File → New → General
```

### Step 2: Load Test Script
```
1. Click "Text Editor" tab (top)
2. Click "New" button
3. Click "Open" button
4. Navigate to: assets/models/characters/blender_scripts/test_all_blockouts.py
5. Click Open
```

### Step 3: Run Test
```
1. Press Alt+P (Run Script)
2. Watch console (bottom panel)
3. Wait for all tests to complete
```

### Step 4: Check Results
```
Console will show:
✅ PASS: JAXON
✅ PASS: KAISON
✅ PASS: KAI-JAX
... (all 9 characters)

🎉 ALL TESTS PASSED!
```

**If you see errors, check the console output for details!**

## 🚨 Troubleshooting

### Script doesn't run?
- Check Blender version (4.0+)
- Check console for errors
- Verify file path is correct

### Model doesn't appear?
- Press Home (frame all)
- Check if hidden (Alt+H to unhide)
- Check collection visibility

### Wrong colors?
- Switch to Material Preview mode
- Check Material Properties panel
- Verify materials created

### Missing features?
- Check console for errors
- Verify all parts created
- Check if parts are separate objects
