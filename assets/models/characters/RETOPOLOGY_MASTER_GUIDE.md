## 🎯 What is Retopology?

**Retopology** is the process of creating clean, optimized topology over your high-poly sculpt. This creates:
- ✅ Clean edge loops for animation
- ✅ Optimized polycount (LOD targets)
- ✅ Proper UV unwrapping
- ✅ Animation-ready mesh

## 🚀 Universal Retopology Workflow

### Phase 1: Setup (30 min)
1. **Duplicate High-Poly**
   - Keep original sculpt
   - Work on duplicate

2. **Enable Shrinkwrap**
   - Add Shrinkwrap modifier
   - Target: High-poly sculpt
   - Mode: Nearest Surface Point

3. **Create Base Mesh**
   - Start with primitive (sphere/cylinder)
   - Match overall shape
   - Low polycount

### Phase 2: Build Topology (4-8 hours)
1. **Edge Loops**
   - Follow muscle flow
   - Add loops at joints
   - Maintain quads

2. **Extrude & Inset**
   - Build form gradually
   - Follow high-poly shape
   - Keep topology clean

3. **Refine Shape**
   - Use Proportional Editing
   - Match high-poly
   - Maintain clean topology

### Phase 3: Special Features (2-4 hours)
1. **Quills/Tails**
   - Separate topology
   - Clean edge loops
   - Animation-ready

2. **Armor/Equipment**
   - Separate meshes
   - Clean topology
   - Optimized

### Phase 4: UV Unwrapping (2-4 hours)
1. **Mark Seams**
   - Strategic placement
   - Minimize distortion
   - Hide seams

2. **Unwrap**
   - Automatic unwrap
   - Check for stretching
   - Adjust as needed

3. **Pack UVs**
   - Efficient packing
   - 80-90% usage
   - No overlapping

### Phase 5: Polish (1-2 hours)
1. **Check Topology**
   - All quads (or clean tris)
   - No n-gons
   - Clean edge flow

2. **Verify Polycount**
   - LOD0 target met
   - Optimized
   - Ready for texturing

### LOD2 (Low Detail)
- 30-40% of LOD0

## 🛠️ Essential Tools

### Blender Retopology Tools
- **Shrinkwrap Modifier** - Snap to high-poly
- **Loop Cut (Ctrl+R)** - Add edge loops
- **Inset Faces (I)** - Create loops
- **Extrude (E)** - Build form
- **Proportional Editing (O)** - Smooth adjustments

### Manual Retopology
- **Poly Build Tool** - Build topology manually
- **F2 Addon** - Quick face creation
- **Snap to Face** - Align to high-poly

## ✅ Quality Checklist

**Topology is ready when:**
- ✅ All quads (or clean tris)
- ✅ Edge loops follow muscle flow
- ✅ Joints have extra loops
- ✅ No n-gons
- ✅ Polycount within target
- ✅ UVs unwrapped and packed
- ✅ Ready for texturing
