## 🚀 Immediate Next Steps (2 Minutes)

### Step 1: Verify Blockout
```
Press NumPad 1: Front view
Press NumPad 3: Side view  
Press NumPad 7: Top view
```
- Check proportions look right
- Verify 7 quills visible
- Body should be Electric Blue

### Step 2: Enter Sculpt Mode
```
Press Tab (toggles Edit/Object mode)
Or: Mode menu (top) → Sculpt Mode
```

### Step 3: Start Sculpting!

**First: Refine Body Shape**
1. **Select Grab Tool** (G key)
2. **Click and drag** on body to reshape
3. Make it more streamlined (speedster form)
4. Smooth out rough edges

**Second: Detail the Quills**
1. **Select each quill** (or sculpt them)
2. **Refine shape** - make them sharper
3. **Add slight curve** (not perfectly straight)

**Third: Add Facial Features**
1. **Use Draw brush** to add mouth line
2. **Use Inflate** to add nose bump
3. **Refine eye positions**

## 🎨 Sculpting Tools Quick Reference

### Essential Tools
```
G: Grab - Reshape overall form
Shift: Smooth - Smooth out rough areas (hold while using any brush)
I: Inflate - Add volume
K: Crease - Create sharp edges
Draw: Add detail
```

### Brush Controls
```
F: Brush size (scroll or drag)
Shift+F: Brush strength
X: Mirror X-axis
Ctrl: Invert brush (subtract/smooth)
```

### Navigation
```
Middle Mouse: Rotate view
Shift+Middle Mouse: Pan
Scroll Wheel: Zoom
NumPad 1/3/7: Front/Side/Top views
```

## 💡 Pro Sculpting Tips

1. **Work from Large to Small**
   - Start with big shape changes
   - Then add medium details
   - Finally add small details

2. **Check from All Angles**
   - Rotate view frequently
   - Check front, side, top, 3/4
   - Silhouette is important

3. **Use Reference**
   - Keep REFERENCE.md open
   - Compare proportions
   - Match the design

4. **Don't Over-Sculpt**
   - Stylized, not realistic
   - Keep it clean
   - Less is more

5. **Save Versions**
   - Save as: `Jaxon_Sculpt_v1.blend`
   - Save frequently
   - Keep backups

## 🚨 Common Issues

### Issue: Model looks blocky
**Fix:** Increase Subdivision levels (3-4), use Smooth brush

### Issue: Quills look wrong
**Fix:** Check quill positions in REFERENCE.md, adjust angles

### Issue: Can't see details
**Fix:** Increase Subdivision, use smaller brush, zoom in

### Issue: Sculpting too much
**Fix:** Step back, check REFERENCE.md, less is more
