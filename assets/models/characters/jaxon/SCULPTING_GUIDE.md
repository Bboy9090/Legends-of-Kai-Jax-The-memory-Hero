# Jaxon Sculpting Guide
## Step-by-Step Beast-Kin Sculpting Workflow

**Character:** Jaxon - The Unstoppable Force 🦔  
**Difficulty:** ⭐ Beginner-Friendly  
**Estimated Time:** 8-16 hours

---

## 🚀 Phase 1: Blockout Refinement (30 min - 1 hour)

### Step 1.1: Verify Blockout
After running script, check:
- [ ] Body: 0.8 × 0.6 × 0.9 units
- [ ] 7 quills visible
- [ ] Head positioned correctly
- [ ] Proportions feel right

### Step 1.2: Refine Body Shape
1. **Enter Sculpt Mode** (Tab)
2. **Select Grab Tool** (G)
3. **Reshape Body:**
   - Make more streamlined (speedster form)
   - Forward-leaning posture
   - Lean, athletic build
   - Smooth curves

4. **Smooth Rough Areas:**
   - Hold Shift
   - Drag over blocky areas
   - Create organic flow

---

## 🎨 Phase 2: Primary Forms (2-4 hours)

### Step 2.1: Body Sculpting

**Create Streamlined Form:**
1. **Use Grab Tool** (G)
   - Pull body forward (ready-to-run pose)
   - Narrow waist slightly
   - Broaden shoulders (athletic)

2. **Add Subtle Muscle Definition:**
   - Use Draw brush (low strength)
   - Define arm muscles (subtle)
   - Define leg muscles (subtle)
   - **Don't overdo it** (stylized, not realistic)

3. **Create Aerodynamic Shape:**
   - Smooth all surfaces
   - Create speed-focused silhouette
   - Forward-leaning posture

### Step 2.2: Head Sculpting

**Refine Hedgehog Head:**
1. **Shape Head:**
   - Use Grab to refine head shape
   - Slightly elongated snout
   - Rounded top

2. **Add Facial Features:**
   - **Mouth:** Use Draw brush (subtle line)
   - **Nose:** Use Inflate (small bump)
   - **Cheeks:** Use Smooth (round out)

3. **Expression:**
   - Determined, energetic
   - Slight smile (confident)
   - Eyes forward (focused)

### Step 2.3: Limb Sculpting

**Refine Arms:**
1. **Shape Arms:**
   - Streamlined, athletic
   - Subtle muscle definition
   - Natural flow

2. **Refine Legs:**
   - Spring-like (ready to jump)
   - Athletic build
   - Smooth curves

---

## ⚡ Phase 3: Quill System (2-4 hours)

### Step 3.1: Refine Quill Shapes

**Each of 7 Quills:**
1. **Select Quill:**
   - Enter Edit Mode
   - Select quill geometry
   - Or sculpt directly

2. **Shape Quill:**
   - Use Grab to adjust angle
   - Use Draw to add volume
   - Use Crease to sharpen tip
   - Create slight curve (not straight)

3. **Quill Positions:**
   - **Left Side:** 3 quills (angled outward)
   - **Right Side:** 3 quills (angled outward)
   - **Center:** 1 quill (straight up/back)

4. **Quill Details:**
   - Sharp tips (not rounded)
   - Slight curves (natural)
   - Good angles (speed lines)

### Step 3.2: Quill Angles

**Verify Angles:**
- Left quills: 30-45° outward
- Right quills: 30-45° outward
- Center quill: 90° (straight up/back)
- Vary slightly for natural look

---

## 🎨 Phase 4: Surface Details (2-4 hours)

### Step 4.1: Fur Direction

**Add Subtle Fur Flow:**
1. **Use Draw Brush** (low strength)
2. **Create Fur Lines:**
   - Direction: Back to front
   - Top to bottom
   - Subtle (not overdone)
   - Stylized, not realistic

3. **Smooth Fur:**
   - Use Smooth brush
   - Create organic flow
   - Don't make it too detailed

### Step 4.2: Muscle Definition

**Add Subtle Definition:**
1. **Arms:**
   - Subtle bicep definition
   - Subtle tricep definition
   - Smooth transitions

2. **Legs:**
   - Subtle quad definition
   - Subtle calf definition
   - Athletic build

3. **Torso:**
   - Subtle abs (very subtle)
   - Lean, streamlined
   - Speed-focused

---

## ✨ Phase 5: Polish (2-4 hours)

### Step 5.1: Final Refinement

**Smooth Everything:**
1. **Use Smooth Brush:**
   - Go over entire model
   - Remove any artifacts
   - Create clean surfaces

2. **Check Proportions:**
   - Front view (NumPad 1)
   - Side view (NumPad 3)
   - Top view (NumPad 7)
   - 3/4 view

3. **Refine Details:**
   - Quill tips sharp
   - Facial features clear
   - Body streamlined
   - Limbs natural

### Step 5.2: Quality Check

**Verify:**
- [ ] Body shape streamlined
- [ ] 7 quills properly shaped
- [ ] Face has character
- [ ] Proportions match REFERENCE.md
- [ ] Looks good from all angles
- [ ] Ready for retopology

---

## 🎯 Key Focus Areas

### Must Get Right:
1. **Streamlined Form** - Speed-focused silhouette
2. **7 Quills** - All positioned and shaped correctly
3. **Forward Posture** - Ready-to-run stance
4. **Electric Blue** - Color will be in materials

### Don't Overdo:
1. **Muscle Definition** - Keep it subtle
2. **Fur Detail** - Stylized, not realistic
3. **Facial Features** - Simple, expressive

## ✅ Success Criteria

**Jaxon is sculpted correctly when:**
- ✅ Body is streamlined (speedster)
- ✅ 7 quills are sharp and positioned
- ✅ Face has determined expression
- ✅ Proportions match REFERENCE.md
- ✅ Silhouette is strong
- ✅ Ready for retopology

---

## 🚨 Common Issues

### Issue: Quills look wrong
**Fix:** Check angles in REFERENCE.md, adjust with Grab tool

### Issue: Body too blocky
**Fix:** Increase subdivision, use Smooth brush liberally

### Issue: Face lacks character
**Fix:** Add subtle mouth line, nose bump, refine eyes

### Issue: Not streamlined enough
**Fix:** Use Grab to pull body forward, narrow waist
