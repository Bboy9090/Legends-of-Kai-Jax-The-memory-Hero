## 🚀 Quick Start (5 Minutes)

### Step 1: Open Blender
1. Launch Blender 4.0+
2. File → New → General

### Step 2: Set Up Scene
1. **Set Units:**
   - Scene Properties → Units
   - Unit System: Metric
   - Unit Scale: 1.000

2. **Configure Viewport:**
   - Viewport Shading → Material Preview
   - Enable Backface Culling (for silhouette check)

3. **Set Grid:**
   - Overlays → Grid
   - Scale: 1.0 (1 unit = 1 meter)

### Step 3: Load Reference
- Keep `REFERENCE.md` open for specs
- Keep `MODELING_GUIDE.md` open for workflow
- Keep `CHECKLIST.md` open to track progress

### Step 4: Begin Blockout
Follow **Phase 1** in `MODELING_GUIDE.md`

## 🎯 Your First Task

**Create the Blockout:**

1. **Create Body Sphere**
   ```
   Shift+A → Mesh → UV Sphere
   Scale: (0.8, 0.8, 0.9)
   Position: Z = 0.45
   Name: "Jaxon_Body"
   ```

2. **Check Dimensions**
   - Body length: 0.8 units ✓
   - Height: 0.9 units ✓
   - Width: 0.6 units ✓

3. **Verify from All Angles**
   - Front (NumPad 1)
   - Side (NumPad 3)
   - Top (NumPad 7)

**✅ Done?** Move to Phase 2 in `MODELING_GUIDE.md`
