1. **Open Blender 4.0+**
   ```
   File → New → General
   ```

2. **Load Script**
   ```
   Text Editor tab → New → Open
   Navigate to: assets/models/characters/jaxon/blender_scripts/generate_jaxon_blockout.py
   ```

3. **Run Script**
   ```
   Press Alt+P
   ```

4. **Watch Console**
   - Should see: "Creating Jaxon base body..."

### STEP 4: Begin Sculpting! (7 min)

#### 4.1: Enter Sculpt Mode
```
Select Jaxon_Blockout
Press Tab (or Mode menu → Sculpt Mode)
```

#### 4.2: First Sculpting Actions

**Grab Tool (Reshape Body):**
```
Press G (Grab tool)
Click and drag on body
Make it more streamlined
Create forward-leaning posture
```

**Smooth Tool (Smooth Rough Areas):**
```
Hold Shift (smooths while using any brush)
Drag over rough/blocky areas
Smooth everything
```

**Adjust Brush Size:**
```
Press F
Drag mouse or scroll wheel
Larger = bigger changes
```

#### 4.3: Refine Body Shape
- Streamline the form (speedster aesthetic)
- Forward-leaning posture
- Lean, athletic build
- Smooth curves

#### 4.4: Check from All Angles
```
NumPad 1: Front view
NumPad 3: Side view
NumPad 7: Top view
Middle Mouse: Rotate view
```

**✅ Sculpting Started!**

## 🎨 Sculpting Tools Reference

### Essential Tools
```
G: Grab - Reshape form
Shift: Smooth - Smooth areas (hold while using any brush)
I: Inflate - Add volume
K: Crease - Sharp edges
Draw: Add detail
```

### Controls
```
F: Brush size
Shift+F: Brush strength
X: Mirror X-axis
Ctrl: Invert (subtract/smooth)
```

### Navigation
```
Middle Mouse: Rotate
Shift+Middle Mouse: Pan
Scroll: Zoom
NumPad 1/3/7: Front/Side/Top
```

## 🚨 Troubleshooting

### Script didn't run?
- Check Blender version (4.0+)
- Check console for errors
- Try copying script manually

### Can't see model?
- Press Home (frame all)
- Check Material Preview mode
- Verify object is selected

### Can't sculpt?
- Make sure in Sculpt Mode
- Check Subdivision modifier active
- Increase subdivision if needed

### Model looks wrong?
- Check dimensions
- Compare to REFERENCE.md
- Adjust in Edit Mode
