# ⚡ RUN SCRIPT → CHECK → SCULPT
## Complete Workflow in 10 Minutes

---

## 🚀 STEP 1: Run the Script (2 minutes)

### In Blender:

1. **Open Blender 4.0+**
   - File → New → General

2. **Load Script**
   - Click **Text Editor** tab (top)
   - Click **New** button
   - Click **Open** button
   - Navigate to: `assets/models/characters/jaxon/blender_scripts/generate_jaxon_blockout.py`
   - Click Open

3. **Run Script**
   - Press **Alt+P** (or click Run Script button)
   - Wait 5-10 seconds
   - Watch the console for progress messages

4. **Verify Output**
   - You should see: "✅ JAXON BLOCKOUT CREATED!"
   - Blue body appears in viewport
   - 7 quills visible on back

**✅ Step 1 Complete!**

---

## ✅ STEP 2: Check the Blockout (2 minutes)

### Verify Dimensions

1. **Select Jaxon_Blockout**
   - Click on the blue body
   - Should be named "Jaxon_Blockout"

2. **Check Dimensions**
   - Properties panel → Item tab
   - Dimensions should be approximately:
     - X: 0.6 (width)
     - Y: 0.8 (length)
     - Z: 0.9 (height)

3. **Check from All Angles**
   ```
   NumPad 1: Front view - Should see head, body, arms, legs
   NumPad 3: Side view - Should see profile, quills on back
   NumPad 7: Top view - Should see 7 quills arranged
   ```

4. **Verify Parts**
   - [ ] Body sphere (blue)
   - [ ] Head sphere (on top)
   - [ ] 2 Arms (attached to body)
   - [ ] 2 Legs (attached to body)
   - [ ] 7 Quills (on back, angled)
   - [ ] 2 Eyes (green, on head)

**✅ Step 2 Complete!**

---

## 🎨 STEP 3: Add Subdivision (1 minute)

### The script already added it, but verify:

1. **Select Jaxon_Blockout**
   - Click on the body

2. **Check Modifiers**
   - Properties panel → Modifier Properties (wrench icon)
   - Should see: **Subdivision Surface**
   - Viewport: 2
   - Render: 3

3. **If Missing, Add It:**
   - Click **Add Modifier** button
   - Select **Subdivision Surface**
   - Viewport: 2
   - Render: 3

**✅ Step 3 Complete!**

---

## 🎨 STEP 4: Begin Sculpting (5 minutes setup)

### Enter Sculpt Mode

1. **Select Jaxon_Blockout**
   - Click on the body

2. **Enter Sculpt Mode**
   - **Option A:** Press **Tab** (toggles modes)
   - **Option B:** Mode menu (top) → **Sculpt Mode**

3. **Verify You're in Sculpt Mode**
   - Toolbar should show sculpting brushes
   - Viewport should show sculpting interface

### First Sculpting Actions

1. **Select Grab Tool**
   - Press **G** key
   - Or: Click Grab brush in toolbar

2. **Reshape Body**
   - Click and drag on body
   - Make it more streamlined
   - Create forward-leaning posture

3. **Smooth Rough Areas**
   - Hold **Shift** (smooths while using any brush)
   - Drag over rough areas
   - Smooth out blocky parts

4. **Adjust Brush Size**
   - Press **F** key
   - Drag mouse or scroll wheel
   - Larger brush = bigger changes

**✅ Step 4 Complete! You're sculpting!**

## 🚨 Troubleshooting

### Can't enter Sculpt Mode?
- Make sure object is selected
- Check object type (should be Mesh)
- Try Tab key to toggle modes

### Sculpting not working?
- Check Subdivision modifier is active
- Increase subdivision levels if needed
- Make sure you're in Sculpt Mode

### Model looks wrong?
- Check dimensions in Properties
- Compare to REFERENCE.md
- Adjust in Edit Mode if needed
