# Jaxon Retopology - Quick Start
## Fast Track to Clean Topology

**Time:** 4-8 hours  
**Difficulty:** Intermediate

---

## ⚡ Fast Path (4 Steps)

### Step 1: Setup (5 min)
1. **Duplicate High-Poly**
   ```
   Select Jaxon_HighPoly
   Shift+D (duplicate)
   H (hide original)
   ```

2. **Run Retopology Helper**
   ```
   Text Editor → Open → retopology_helper.py
   Alt+P (run script)
   ```

3. **Base Mesh Created**
   - Shrinkwrap modifier added
   - Ready to build topology

### Step 2: Build Topology (3-6 hours)
1. **Enter Edit Mode** (Tab)
2. **Add Edge Loops** (Ctrl+R)
   - Chest loop
   - Waist loop
   - Hip loop
   - Joint loops (shoulders, elbows, hips, knees)

3. **Refine Shape**
   - Use Proportional Editing (O)
   - Match high-poly shape
   - Maintain quads

### Step 3: Quills (1-2 hours)
1. **Create Quill Topology**
   - 8-12 sides per quill
   - Clean edge loops
   - Match high-poly

### Step 4: UV Unwrap (1-2 hours)
1. **Mark Seams**
   - Under arms
   - Inner legs
   - Back center
   - Around quills

2. **Unwrap** (U → Unwrap)
3. **Pack** (UV → Pack Islands)

---

## ✅ Done!

**Check:**
- [ ] Polycount: 35,000-45,000 tris
- [ ] All quads (or clean tris)
- [ ] UVs unwrapped
- [ ] Ready for texturing
