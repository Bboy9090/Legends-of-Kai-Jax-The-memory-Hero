## ⚡ FASTEST PATH (5 Minutes to Blockout)

### Step 1: Open Blender
1. Launch Blender 4.0+
2. File → New → General

### Step 2: Load Script
1. Click **Text Editor** tab (top)
2. Click **New** button
3. Click **Open** button
4. Navigate to: `assets/models/characters/jaxon/blender_scripts/generate_jaxon_blockout.py`
5. Open the file

### Step 3: Run Script
1. Press **Alt+P** (or click Run Script button)
2. Wait 5-10 seconds
3. **BOOM!** Jaxon blockout appears!

### Step 4: Verify
- You should see:
  - ✅ Blue body sphere
  - ✅ Head on top
  - ✅ Arms and legs
  - ✅ 7 quills on back
  - ✅ 2 green eyes

### Step 5: Save
- File → Save As
- Name: `Jaxon_Blockout_v1.blend`
- Location: `assets/models/characters/jaxon/`

## 🚨 Troubleshooting

### Script didn't run?
- Check Blender version (4.0+)
- Check console for errors (Window → Toggle System Console)
- Try copying script manually

### Blockout looks wrong?
- Check dimensions (see QUICK_START_COMMANDS.md)
- Adjust scale in Edit Mode
- Verify quill positions

### Materials not showing?
- Switch to Material Preview mode
- Assign materials manually in Material Properties
- Check material names match
