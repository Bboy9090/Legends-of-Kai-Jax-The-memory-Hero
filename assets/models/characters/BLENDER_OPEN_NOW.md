## 🚨 If You See Errors

### Common Issues:

1. **"File not found"**
   - Check file path is correct
   - Make sure you're in the right folder

2. **"Syntax error"**
   - Check Blender version (need 4.0+)
   - Try updating Blender

3. **"Module not found"**
   - Shouldn't happen - script is self-contained
   - Check Blender version

4. **Model doesn't appear**
   - Press **Home** (frame all)
   - Check if hidden: **Alt+H** (unhide)
   - Check collection visibility
