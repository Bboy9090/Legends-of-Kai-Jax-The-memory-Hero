## 🚀 Quick Start (Any Character)

### Step 1: Open Blender
1. Launch Blender 4.0+
2. File → New → General

### Step 2: Load Script
1. Text Editor → New → Open
2. Navigate to: `assets/models/characters/[character]/blender_scripts/generate_[character]_blockout.py`
3. Open the file

### Step 3: Run Script
1. Press **Alt+P** (Run Script)
2. Wait 5-10 seconds
3. **Blockout appears!**

### Step 4: Begin Sculpting
1. Press **Tab** (Enter Sculpt Mode)
2. Use **G** (Grab) to reshape
3. Use **Shift** (Smooth) to smooth
4. Follow REFERENCE.md for details
