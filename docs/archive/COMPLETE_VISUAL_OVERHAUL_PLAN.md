### 1.2 Material System (PBR)

**All characters use Physically Based Rendering:**
- **Albedo Maps:** Base colors per character
- **Metallic Maps:** 0.2-0.5 (organic feel)
- **Roughness Maps:** 0.3-0.7 (varied textures)
- **Emissive Maps:** Glowing eyes, auras, energy effects
- **Normal Maps:** Scale details, fur texture, muscle definition

### 1.3 Animation System

**All characters have:**
- Idle animations (breathing, tail swishes, aura pulses)
- Combat animations (attacks, dodges, blocks)
- Movement animations (walk, run, jump, dash)
- Special animations (transformations, ultimates, reactions)
- Emotion animations (anger, focus, victory, defeat)
