# Fighter Select V2 Scope Lock

The first V2 slice is limited to the existing Versus character-select surface.

In scope:

- input navigation
- persisted current selection
- accessible state and focus
- responsive roster layout
- standard/training/back actions
- deployment and review evidence

Out of scope for this slice:

- inventing unlock progression
- rewriting fighter lore
- replacing 3D assets
- changing battle balance
- expanding the roster

Those remain separate changes so the input/accessibility pass can be reviewed without unrelated gameplay churn.
