## Known Limitations

Do not expect these features or capabilities in v0.1.0-mvp:

❌ **NOT verified:**
- All 15 missions individually playable end-to-end
- All 6 boss encounters individually tested
- All 100+ playable characters rendering without error
- Frame-time stability or latency guarantees
- Live Vercel deployment gameplay
- Deployed commit SHA confirmation
- Android signed/release build
- iOS signed/App Store build
- Desktop (Electron) packaged build
- Offline mode (service worker disabled intentionally)
- Gamepad input support
- Narrative branching or multiple endings

❌ **Known incomplete:**
- 9-tail character rigging (all canonical models lack tail anchors; graceful degradation in place)
- Kai-Jax tail-rig prototype (weight-painting incomplete, visual strain in heavy combat poses)
- Some UI placeholder artwork (pending artist final approval)
- Full TypeScript scope outside Phase 0 profile (pre-existing errors, out of scope for MVP)

❌ **Known issues (non-blocking):**
- Some model-loading paths divergent (registry vs filename guessing) — both work, not unified
- Service-worker registration disabled (offline not guaranteed)
- Two broken root validation scripts (`validate:canon`, `validate:memory`)
- Registry debug overlay not wired up (dormant code)

See [`docs/known-debt.md`](../known-debt.md) for the full classified tracker.
