## 🎯 QUICK REFERENCE GUIDE

### CORE CONCEPTS

**The Weave:** The frequency of existence (Noise, Life, Connection)  
**The Source:** The entropic void (Silence, Erasure, Deletion)  
**Core Resonance:** Power level measured in tiers (Dormant → Harmonized → Ascended)  
**Matte-Mythic:** Visual aesthetic (no plastic, no neon, heavy silhouettes, zero saturation)

### MAIN CHARACTERS

**Kai-Jax:** Fused brothers (Jaxon + Kaison), three tails (Red/Blue/Amber), Memory Hero  
**Silver:** Wolf-Falcon hybrid, T-minus-10 foresight, Ascended Will  
**Lunara:** Feline-Serpent hybrid, gravity manipulation, Oracle of Fate  
**Bovarr:** Great Ursine, Kai-Jax's father, spirit lives in core (Paternal Anchor)

### KEY LOCATIONS

**Prime Pillar:** Ancient arena, site of Trial of Sovereignty, Star-Forge location  
**Iron Canyons:** Jaxon/Kaison's home, Bovarr's base, Resistance hideout  
**The Whispering Wilds:** Forest territory, Void-drone patrols  
**Void-Citadel:** Malakor's base, Lunara's prison (Book 5)

### 9-BOOK STRUCTURE

**Volume I: THE COLLAPSE**
- Book 1: The Breaking Point (Bovarr dies, Kai-Jax born)
- Book 2: The Silent Year (Resistance fights guerrilla war)
- Book 3: Shatter-Vaults (Find Silver, restore memory)

**Volume II: THE AWAKENING**
- Book 4: Hidden Thrones (Saurian/Aviary clans unite)
- Book 5: The Warden's Oath (Rescue Lunara, Iron Titan dies)
- Book 6: Storm Crowns (Spark-Hatchling ascends, Trinity reunited)

**Volume III: THE END-WAR**
- Book 7: Convergence (Physical world merges with Void)
- Book 8: The Multiverse Gauntlet (All-High's final trial)
- Book 9: The Eternal Weave (Total war, Void integrated into Weave)

## 🎨 VISUAL GUIDELINES

### COLOR LANGUAGE

- **Amber/Gold:** Bovarr, memory, protection (warmth)
- **Red:** Jaxon, grit, power (intensity)
- **Blue:** Kaison, wisdom, precision (clarity)
- **White/Silver:** Silver, foresight, purity (detachment)
- **Purple/Midnight:** Lunara, fate, mystery (depth)
- **Static/Greyscale:** Void, silence, erasure (coldness)

### AESTHETIC RULES

1. **No Plastic:** Deep textures only (fur, stone, metal)
2. **No Neon:** Desaturated palette with selective color pops
3. **Heavy Silhouettes:** Every character readable in shadow
4. **Heat Distortion:** High resonance = visible air warping
