# Legends of Kai-Jax — Canonical Store Asset Contract

## Public identity
**Legends of Kai-Jax: The Memory Hero**

Store display may use **Legends of Kai-Jax** where platform title limits require it. **The Memory Hero** remains the franchise subtitle.

## Compatibility identities
Preserve:
- Capacitor app ID `com.bobbyblanco.legendsofkaijax`
- desktop app ID `com.legends-of-kai-jax.desktop`
- save keys and progression schemas
- mission IDs
- model registry identifiers
- repository lineage

## Canonical art authority
Store icons, splash screens, screenshots, feature graphics, and APK/AAB assets must use the currently approved Kai, Jax, and Kai-Jax character designs from the locked visual library.

Do **not** revive older character silhouettes, costumes, colors, or placeholder artwork merely because a legacy APK or icon still contains them.

Allowed transformations of canonical source art:
- crop
- scale
- safe-area composition
- lighting/background treatment that does not alter the character design
- store-platform masking

Not allowed without explicit art approval:
- redesigning faces, fur, costumes, tails, colors, weapons, body proportions, or fusion identity
- replacing canonical art with generic AI character substitutes

## Icon direction
Primary store mark should remain readable without text:
- Kai/Jax dual-silhouette or bonded-tail motif
- Memory Hero / memory-weave cue
- strong cyan + warm accent contrast already associated with the current game family
- no generic `KJ` text-only badge as the final store icon

## Splash / launch
- canonical Kai and Jax lead composition
- Kai-Jax / Memory Hero presence may be used as the central reveal
- title: **Legends of Kai-Jax**
- subtitle: **The Memory Hero**
- no gameplay claims on splash art

## Required store exports
- 1024×1024 iOS/App Store icon
- Android adaptive foreground/background master
- 512×512 Play icon
- 1024×500 Play feature graphic
- 2732×2732 launch composition
- iPhone / iPad screenshot sets
- Android phone / tablet screenshot sets
- desktop 1024 master plus ICNS/ICO/PNG derivations

## Current release truth
Verified repository state currently supports:
- Web/PWA production build and playable 15-mission vertical slice
- Android debug APK CI path
- documented Capacitor iOS build path
- desktop packaging tooling

Not yet proven by current repository evidence:
- signed Android release AAB accepted by Play
- signed iOS archive accepted by App Store Connect
- packaged desktop installers exercised on target OSes
- full physical-device playthrough of all missions
- final canonical store art wired into every native target

These remain separate release gates.
