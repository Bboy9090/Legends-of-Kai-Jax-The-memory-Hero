## 🚀 DEPLOY NOW (5 Steps)

### 1️⃣ Create GitHub Repository
- Go to: https://github.com/new
- Name: `Aeterna-Covenant`
- Set to **Public**
- Click "Create repository"

### 2️⃣ Connect Git (In Cursor Terminal)
```bash
git init
git remote add origin https://github.com/YOUR_USERNAME/Aeterna-Covenant.git
git branch -M main
```

### 3️⃣ Run Deployment Script
**Windows:**
```powershell
.\deploy\deploy.ps1
```

**Mac/Linux:**
```bash
chmod +x deploy/deploy.sh
./deploy/deploy.sh
```

### 4️⃣ Enable GitHub Pages
1. GitHub Repo → **Settings**
2. **Pages** (left sidebar)
3. **Source:** Select "GitHub Actions"
4. Wait 2-3 minutes

### 5️⃣ Play Your Game!
Visit: `https://YOUR_USERNAME.github.io/Aeterna-Covenant`

**Install on iPad:**
- Safari → Share → "Add to Home Screen"
