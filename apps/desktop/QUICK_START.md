# 🚀 QUICK START - Enterprise Desktop App

## ⚡ Get Started in 3 Steps

### **1. Install Dependencies**
```bash
cd apps/desktop
pnpm install
```

### **2. Build TypeScript**
```bash
pnpm build:ts
```

### **3. Run in Development**
```bash
pnpm dev
```

---

## 📦 Build for Production

### **Windows**
```bash
pnpm build:win
```

### **macOS**
```bash
pnpm build:mac
```

### **Linux**
```bash
pnpm build:linux
```
