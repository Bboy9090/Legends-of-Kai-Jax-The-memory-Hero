Legends of Kai-Jax — Privacy Policy

Effective: September 26, 2026

Legends of Kai-Jax is designed to minimize collection of personal information. The current mobile game does not require an account to play.

Information stored on your device

The game stores gameplay progress, save slots, settings, audio/voice preferences, and offline game-state information locally on your device using browser storage technologies such as localStorage and IndexedDB. This information is used to provide save/load, preferences, and offline functionality.

Network activity

The game may request application assets required to run the game. Core combat move data, models, sounds, and other gameplay resources are loaded as application resources. The current mobile game does not include third-party advertising SDKs or third-party analytics SDKs.

Voice features

Where supported, character voice playback uses the device or browser Web Speech API. Voice preferences are stored locally on the device.

Children

The game is not designed to collect personal information from children. If future features introduce accounts, online social features, analytics, advertising, purchases, or other data collection, this policy will be updated before those features are released.

Data sharing and sale

The current mobile game does not sell personal information. The current mobile game does not share personal information with advertising networks.

Data deletion

Because current gameplay data is stored locally, users can remove local game data by clearing the app's storage or uninstalling the app. Save-slot deletion features may also remove individual locally stored saves.

Changes to this policy

This policy may be updated as the game evolves. Material changes to data practices will be reflected here before the related feature is released.
