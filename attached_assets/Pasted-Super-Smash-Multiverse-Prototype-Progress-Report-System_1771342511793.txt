⚙️ Systems Expansion: Ledge & Recovery Engine (Competitive Backbone)

Platform fighters live or die on ledge rules. This pass locks in a clear, traditional, tournament-grade system — readable, punishable, fair.

Implemented mechanics
	•	Ledge Snap Cone
	•	Character auto-snaps only if facing ledge within angle window
	•	Prevents “teleport grabs” from behind
	•	Fresh Ledge Invulnerability
	•	Short invuln on first grab
	•	Reduced on repeated grabs
	•	Regrab Lockout
	•	Touch stage or get hit before grabbing again
	•	Ledge Options
	•	Neutral getup
	•	Roll
	•	Jump
	•	Attack (frame‑vulnerable startup)

// ledge_system.ts
export function trySnapToLedge(player, ledge){
  if(player.regrabLocked) return false;

  const angle = angleBetween(player.facing, ledge.direction);
  if(angle > SNAP_CONE) return false;

  player.state = "LEDGE_HANG";
  player.invuln = player.freshGrab ? 40 : 18;
  player.freshGrab = false;
  return true;
}

Result: Edge-guarding now feels intentional instead of chaotic.
