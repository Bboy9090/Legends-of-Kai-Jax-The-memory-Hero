Character System
Three fighters with complete movesets using MoveSetBuilder pattern:

// Kaison (Fox): Weight 80, Speed 2.4 - Rushdown with momentum combos
// Jaxon (Hedgehog): Weight 75, Speed 3.2 - Fastest, spin-based multi-hits  
// Kaxon (Fusion): Weight 95, Speed 3.5 - 30s timer, requires 100% synergy

class Kaison extends BaseFighter {
  protected createMoveSet(): MoveSet {
    return new MoveSetBuilder()
      .addAttack('jab', { damage: 3, baseKnockback: 10, ... })
      .addSpecial('side_special', { damage: 14, baseKnockback: 40, ... })
      .build();
  }
}
Each character has jabs, heavies, aerials, and 4 specials with frame data (startup/active/recovery).
