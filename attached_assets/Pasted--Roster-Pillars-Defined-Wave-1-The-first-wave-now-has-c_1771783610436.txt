⚔️ Core Combat Identity — “Momentum Clash System”

A new system was prototyped to separate it from existing platform fighters.

Momentum Clash (New Mechanic)

When two attacks collide:

Light vs Light → both recoil

Light vs Heavy → heavy wins

Heavy vs Heavy → screen freeze + pushback

Perfect timing → Clash Burst (both launched apart)

This creates cinematic moments without randomness.
